# Adapting to Host Capabilities

Prefer the current host's skill discovery and invocation entry points when loading skills from this package. When file reading is available, load resources through package-relative paths. Stage skills and shared references are different layers: reading shared material does not also invoke the coordination skill. When delegating, pass the main task entry point, revisions and sources, allowed write scope, workspace, completion criteria, and return requirements. Use a genuinely isolated new context for independent review. Execution in a single workspace is also a valid path.

Use the actual interfaces provided by the current tools for notification, waiting, cancellation, shell termination, and status queries, and verify their effects separately. Before every next affected action, verify that the executor has actually adopted the current requirement and source versions, even when notification receipt was acknowledged. Recheck the basis before accepting a return. On pause, stop further dispatches and inspect in-flight external effects. When a required independent check has no equivalent execution path, leave it unsatisfied and record the conditions needed to resolve it. For each host experiment, record the interface, time, isolation scope, and observed results.
