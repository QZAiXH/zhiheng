# 业务实测反馈入口

在使用项目的任务记录保留原始请求和证据；将可访问入口、脱敏副本或摘要登记到本包的 `docs/tasks/<维护任务>/`。建议每次反馈提供：

| 字段 | 内容 |
|---|---|
| 原始请求与项目条件 | 请求原文、技术环境、阶段、授权范围 |
| 受测版本 | 本包提交或内容指纹、技能名称、模型与工具配置 |
| 预期与观察 | 对应需求/完成条件、实际产物、误触发或缺漏 |
| 证据 | 文件、检查命令、输出、时间和可访问位置 |
| 变化与复验 | 修订、同输入旧版/候选版比较、相邻回归、决定 |

按 `skills/zh/references/improvement.md` 归并跨任务反馈。发现评估仅给请求与候选描述；执行评估记录真实产物。候选退步或证据不足时记录结果并保留有效版本。
