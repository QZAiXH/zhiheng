# 领域与规范

本仓库维护 zhiheng 双层循环开发技能。[README 的日常用法](../../README.md#日常怎么用)说明工单、外环与内环的关系。[规格与工单约定](../../plugins/zhiheng/skills/plan-feature/references/ticket-and-spec.md)说明父规格、切片和依赖的记录方式。第一个需长期复用的术语记入 `GLOSSARY.md`。需要保留理由的架构决策在确认后写入 `docs/adr/`。

交付使用目标修订的 [README 本地验证](../../README.md#本地验证)、[交付证据](../../plugins/zhiheng/skills/accept-delivery/references/delivery-evidence.md)和[独立审查规程](../../plugins/zhiheng/skills/accept-delivery/references/independent-review.md)。用 `git show <revision>:<path>` 打开规则原文，记录文件、章节和 Git 修订。涉及规则变化时，按工单的目标版本和适用条件核对已经确认的决定。
