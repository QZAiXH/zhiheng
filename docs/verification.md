## 独立审查与复验

各切片按 Standards（`harness-engineering`、`skill-creator`、`writing-for-agents`）和 Spec（需求 I-01—I-07）两轴审查。最终独立审查的确定 P2 问题是 TDD 评估重跑覆盖已接受证据，以及技能共存发现的覆盖不足；前者改为拒绝复用运行标识并做成功／超时替身复验，后者追加竞争技能与自然触发证据后复核关闭。来源登记的当前处理与历史观察也已拆列。最终本地基础交付两轴确定 P2 残留为 0，保留一项非阻断的表格组织建议。

开发与行为评估客户端请求为 `gpt-6.1-sol/high`，独立审查客户端请求为 `gpt-6.1-sol/max`，均有对应运行回执；服务端实际模型和最终推理档位不可观测。发现评估记录候选描述与请求，执行评估另外核对实际读取、产物和证据，二者分开解释。历史试验的输出和当前源码变更须按各自版本理解。

## 在本仓库重新检查

准备 Python 3.11+、Git 和独立工具环境，安装 [`requirements.txt`](../skills/zh/scripts/requirements.txt)，然后执行：

```sh
python3 tools/build_package.py
/absolute/path/to/zhiheng-tool-venv/bin/python tools/run_checks.py
```

`run_checks.py` 重建包、检查 17 个入口与资源、运行测试并编译脚本。使用 `tools/check_package.py` 可单独核对生成包的文件指纹。此处的命令验证当前源码和隔离测试，不会重演历史模型会话；原始审计材料需要在保留它们的开发工作区查阅。
